# FinOps AI Agent

This project provides a starter structure for a FinOps-focused AI agent built with FastAPI and LangGraph-inspired modules.

## Project structure

- app/api: FastAPI endpoints
- app/agent: orchestration and graph logic
- app/tools: Azure and FinOps tools
- app/services: business logic
- app/database: persistence layer
- app/config: settings and logging
- app/core: shared application utilities
- app/schemas: request and response models
- app/utils: helper functions
- app/mcp: MCP integration modules
